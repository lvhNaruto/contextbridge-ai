# Sponsor resources and technical availability

**Research date:** 2026-09-23

## Confirmed by official pages

The accessible official materials name these technologies/platforms:

- Google Cloud technology stack
- Gemini
- Gemma
- Agent Platform
- Antigravity
- AI Studio
- Cloud Run
- Firebase
- Google Cloud / GCP deployment

The site also says online sessions covering the program and problem statements will be hosted, and provides an AI Builder Cup Discord community.

## No official allocation verified

The inspected official pages do **not** publish or confirm:

- Google Cloud credits
- Gemini API credits
- Firebase or Cloud Run quotas
- Vertex AI project grants
- API keys
- Sponsor-provided cloud accounts
- SDK download bundles or required SDK versions
- Specific Gemini/Gemma model versions
- Regional project configuration
- A complete API catalog

Do not assume any of these are included. Obtain confirmation from the organizer or the authenticated registration/community channels.
